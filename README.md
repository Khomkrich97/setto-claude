# Setto Claude

หน้าต่างแชทสำหรับใช้ Claude Code บน Windows ด้วยบัญชี Claude ของบริษัท แยกจากบัญชีส่วนตัว

- วางภาพง่าย ลากไฟล์เข้าหน้าต่าง หรือแคปหน้าจอแล้ว Ctrl+V
- เปิดหลายงานพร้อมกัน ทำต่อจากงานเก่าได้จากประวัติ
- คำสั่ง `/` ครบ (`/init` `/compact` `/review` และ skill ของคุณ)
- เลือกโหมด (Auto, Manual, Accept edits, Plan, Bypass) เลือกโมเดลและ effort ได้
- แผงขวาบอกโฟลเดอร์งาน branch context ที่ใช้ไป connectors ไฟล์ที่ Claude สร้างหรือแก้ และการเปลี่ยนแปลงใน git

## ติดตั้ง

1. ดาวน์โหลด [Setto Claude (ZIP)](https://github.com/Khomkrich97/setto-claude/archive/refs/heads/main.zip) แล้วแตกไฟล์ไว้ที่ไหนก็ได้ ห้ามลบโฟลเดอร์นี้หลังติดตั้ง
2. ดับเบิลคลิก `Setto Claude.bat`
   ครั้งแรกจะติดตั้งสิ่งที่ยังไม่มีให้เอง (Python, Claude Code, library) ใช้เวลาประมาณ 5 ถึง 10 นาที
3. กดปุ่ม **ล็อกอิน** ที่มุมซ้ายบน แล้วล็อกอินด้วยอีเมลบริษัท
4. ครั้งต่อไปเปิดจากไอคอน Setto Claude บนหน้าจอ หรือใน Start menu ปักหมุดไว้ที่ taskbar ได้

ต้องมี Windows 10 หรือ 11 และบัญชี Claude ที่ใช้ Claude Code ได้ (Pro, Max, Team หรือ Enterprise)

## อัปเดต

โปรแกรมเช็คเวอร์ชันใหม่จาก GitHub ทุกครั้งที่เปิด ถ้ามีจะโหลดมาเปลี่ยนให้เองแล้วเปิดใหม่ ไม่ต้องทำอะไร

## ข้อมูลอยู่ที่ไหน

- การล็อกอินบัญชีบริษัท `%USERPROFILE%\.claude-company`
- ถ้าเครื่องนี้ใช้ Claude Code กับบัญชีส่วนตัวอยู่แล้ว ประวัติงาน memory skill และ plugin จะใช้ชุดเดียวกัน
- ไฟล์ของโปรแกรม `%LOCALAPPDATA%\Setto\claude` (ไฟล์แนบเก็บ 7 วัน)
- โปรแกรมเปิดหน้าต่างของตัวเองบนเครื่อง ไม่มีเซิร์ฟเวอร์กลาง ข้อความส่งตรงไป Claude ผ่าน Claude Code
